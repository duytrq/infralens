# InfraLens dashboard

Dev dashboard: **https://ddsw2osqv2rj2.cloudfront.net**. Localhost login remains supported.

Private English-language Terraform security dashboard. React + Vite + TypeScript,
React Router, TanStack Query and oidc-client-ts. It reads the existing backend;
the browser does not upload or parse full Trivy reports.

## Local development

Node 22.22.2 and npm 10.9.7 are the verified toolchain. From `frontend/`:

```bash
npm ci
cp .env.example .env.local
npm run dev
```

Open **http://localhost:5173**, not 127.0.0.1:5173: the Cognito callback is exact.
`VITE_API_BASE_URL` is the public API origin, never a credential. The deployed
backend must enable localhost via `EnableLocalDashboard=true` in dev.
The primary dashboard origin remains the CloudFront URL.

Admin-provisioned Cognito accounts sign in through the hosted login page, using
authorization code + PKCE S256, state and nonce. Tokens are scoped to the tab in
sessionStorage, renewed with refresh tokens, and removed on sign-out or session
failure. A static SPA cannot issue HttpOnly session cookies without a separate
session backend; this release follows the approved direct-Cognito architecture.
CORS origin checks are not IP restrictions or a replacement for authentication.

## Verification

```bash
npm run generate:check
npm run lint
npm run typecheck
npm test
npx playwright install --with-deps chromium
npm run test:e2e
npm run build
npm audit --audit-level=high
```

The committed `.npmrc` disables dependency lifecycle scripts. No install scripts
are needed for this dependency graph: esbuild uses its platform binary package.
The first lockfile was generated with npm 11 after a peer resolver crash in npm
10; a clean npm 10 `ci` install is verified and is the reproducible CI path.
Dependencies are pinned by `package-lock.json`; do not remove it to resolve errors.

OpenAPI is generated by the backend; update it there, then run `npm run generate`.
`src/api/schema.d.ts` is generated and should not be reformatted by hand.
The API wrapper accepts only the configured HTTPS origin, attaches access tokens,
normalizes Lambda/gateway errors, propagates cancellation and bounds GET retries.

Browser tests use mock HTTP responses and isolated test sessions, with no login
bypass in the application. They verify projects/history, filters, empty cursor
pages, safe source rendering, analysis states, downloads, deletion and WCAG checks
at 320/768/1024/1440px. `test-results/` contains local screenshots and traces.

## Dashboard behavior

- Project IDs are permanent. Project creation is idempotent for the same ID/name.
- History uses inclusive scan start timestamps, stored as UTC and displayed in
  the browser's timezone. Pagination uses opaque cursors, not numeric pages.
- Findings filters are AND-combined, exact and case-sensitive. An empty page can
  have a next cursor. File/rule indexes can lag; refresh before assuming no result.
- Upload, indexing and threshold results are separate. Counts are explicitly
  labeled CLI-reported or report-derived; mismatches stay visible.
- Pending analysis polls metadata at 5/10/20/30 seconds, pauses in hidden tabs and
  stops after 20 minutes from the analysis request. Use Refresh after that.
- Legacy/failed analysis supports explicit start/retry. JSON remains downloadable
  if indexing fails; links are obtained when clicked and used for navigation.
- Delete hides a scan after either 202 or 204. Background physical cleanup can
  finish later. It does not delete the project.
- Findings render plain text only. References permit HTTP(S), and missing source
  locations are shown as unavailable. Truncation is labeled; original JSON is full.
- CLI cloud upload is not implemented. Ready reports must already have been
  ingested through the backend API or operator smoke tooling.

## AWS deployment and rollback

See [frontend operations](../infra/FRONTEND.md). CI validates/builds with a mock API
origin and no AWS credentials. The operator publish command rebuilds for the
actual stack endpoint after verification, archives the release, then uploads it.
